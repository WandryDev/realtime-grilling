Подключение ClickUp и задачи ClickUp в проектах.

- В настройках, онбординге и прямо из мастера проекта ClickUp подключается по личному токену из «Settings → Apps». Токен хранится в Keychain (Credential Manager на Windows). Если токен открывает несколько рабочих пространств, при подключении выбирается одно.
- В мастере нового проекта и на странице проекта можно выбрать пространства, папки и списки ClickUp целиком или отдельные задачи с подзадачами. Задача с описанием и последними комментариями становится источником проекта и идёт в бриф.
- Задачи обновляются после изменения выбора, по кнопке «Обновить» и перед звонком. Закрытые задачи из выбранных списков уходят из источников. Приложение укладывается в лимит запросов ClickUp и ждёт его сброса, а не падает с ошибкой.
- Окно выбора документов стало общим для Outline и ClickUp: папки раскрываются по требованию, а если загрузка не удалась, в узле видна ошибка с «Повторить».
- Отключение коннектора прерывает идущую синхронизацию.
- GitHub пока помечен «скоро».
