## Purpose

Готовность локального CLI агента, который придумывает вопросы во время звонка. Первым поддерживается Claude Code. Приложение находит CLI, проверяет вход и подписку, помогает установить его и войти без терминала.

## ADDED Requirements

### Requirement: Поиск агента
Приложение SHALL находить исполняемый файл Claude Code, даже если оно запущено из Finder или меню «Пуск» и не видит PATH из командной оболочки пользователя. Найденный путь SHALL сохраняться в настройках, и следующие проверки и вызовы агента используют его. Если сохранённый путь перестал работать, приложение SHALL искать заново.

#### Scenario: CLI установлен в домашней папке
- **WHEN** Claude Code установлен официальным установщиком в домашнюю папку пользователя, а приложение запущено из Finder
- **THEN** шаг «Агент» находит CLI и показывает его версию

#### Scenario: CLI не установлен
- **WHEN** Claude Code нигде не найден
- **THEN** статус агента `notInstalled`, шаг предлагает «Установить»

### Requirement: Статус агента
Приложение SHALL сообщать статус агента: `notInstalled`, `needsLogin`, `ready` (с версией CLI и типом подписки) или `error` (с текстом для поддержки). Проверка MUST NOT вызывать модель и тратить лимит подписки. Проверка, не уложившаяся в отведённое время, SHALL заканчиваться статусом `error`, а не зависать.

#### Scenario: Вход выполнен
- **WHEN** Claude Code установлен и пользователь вошёл по подписке
- **THEN** статус `ready`, шаг показывает версию и тип подписки, «Продолжить» доступна

#### Scenario: CLI зависает
- **WHEN** запуск CLI не отвечает дольше отведённого времени
- **THEN** процесс завершается, статус `error` с текстом «Claude Code не отвечает»

### Requirement: Установка агента
По кнопке «Установить» приложение SHALL установить Claude Code официальным способом для текущей ОС, без прав администратора и без терминала. Во время установки SHALL показываться прогресс, а после неё — проверка статуса. При сбое статус SHALL быть `error`, текст ошибки сохраняется для кнопки «Скопировать для поддержки», а «Повторить» запускает установку снова. Установку SHALL можно отменить.

#### Scenario: Успешная установка
- **WHEN** пользователь нажимает «Установить» на компьютере без Claude Code
- **THEN** шаг показывает прогресс установки, затем статус `needsLogin` и кнопку «Войти»

#### Scenario: Нет сети
- **WHEN** установка не может скачать файлы
- **THEN** статус `error` с текстом сбоя, кнопки «Повторить» и «Скопировать для поддержки»

### Requirement: Вход в агент
По кнопке «Войти» приложение SHALL запустить вход Claude Code по подписке и открыть страницу входа в браузере. Шаг SHALL показать поле «Код из браузера» и передать введённый код CLI. Неверный или просроченный код SHALL давать ошибку у поля, вход можно повторить. Приложение MUST NOT сохранять код, пароль или токены агента: ими управляет сам CLI.

#### Scenario: Пользователь вошёл в браузере
- **WHEN** пользователь нажимает «Войти», входит в браузере и вставляет показанный код в поле шага
- **THEN** после «Подтвердить» статус становится `ready`

#### Scenario: Неверный код
- **WHEN** пользователь вставляет код, который CLI не принял
- **THEN** у поля появляется ошибка, статус остаётся `needsLogin`, «Войти» начинает вход заново

#### Scenario: Пользователь передумал
- **WHEN** пользователь нажал «Отменить» или код не введён до тайм-аута
- **THEN** процесс входа останавливается, статус остаётся `needsLogin`

### Requirement: Повторная проверка агента
По кнопке «Проверить снова» и при возврате фокуса в окно онбординга приложение SHALL проверять статус агента заново. Так шаг замечает CLI, который пользователь установил или в который вошёл сам, в терминале.

#### Scenario: Вход через терминал
- **WHEN** пользователь выполнил вход в Claude Code в терминале и вернулся в окно онбординга
- **THEN** шаг показывает статус `ready`
