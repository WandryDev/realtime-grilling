# Spec Delta

## MODIFIED Requirements

### Requirement: Файлы записи
Каждый канал SHALL сохраняться в отдельный файл Ogg Opus (моно), который открывают обычные плееры. Часовой звонок MUST занимать не больше 25 МБ на оба канала. Файлы SHALL храниться только в папке данных приложения на этом компьютере. Запись MUST NOT покидать машину. Менеджер SHALL иметь возможность удалить аудио звонка: файлы его записей удаляются с диска, а запись остаётся без аудио. Второй проход распознавания MUST NOT запускаться для записи без аудио.

#### Scenario: Часовой звонок
- **WHEN** запись идёт час
- **THEN** оба файла вместе занимают не больше 25 МБ и воспроизводятся в QuickTime или VLC

#### Scenario: Аудио удалено до второго прохода
- **WHEN** менеджер удалил аудио звонка, пока второй проход ещё не начался
- **THEN** второй проход для этих записей не запускается, а живая расшифровка остаётся
