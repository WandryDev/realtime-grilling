## Context

- Дизайн-система Grill (Paper, «Design System») описана как «ink on paper», только светлая. Токены лежат в `:root` в `src/app/globals.css`, Tailwind читает их через `@theme inline`; shadcn-имена (`background`, `primary`, …) указывают на те же значения. `@custom-variant dark (&:is(.dark *))` уже есть.
- `ThemeProvider` (next-themes) стоит в корневом layout с `forcedTheme="light"`.
- Настройка `theme` хранится в SQLite, Rust принимает `light` / `dark` / `system`, по умолчанию `light`. Настройки читает `settingsStore` (`createSyncedStore`): в Tauri он в `loading` до первого чтения и перечитывает себя на `DataChanged` из любого окна.
- Окон четыре, все объявлены в `tauri.conf.json` и создаются скрытыми; виджет и оверлей прозрачные, без рамки и тени окна.
- Тени в дизайне — четыре уровня (`touch`, `card-sm`, `card`, `float`) из `rgb(17 17 17 / …)`, на тёмном они не видны.

## Goals / Non-Goals

**Goals:** настоящая тёмная тема для всех экранов и окон; «Как в системе»; переключение без перезагрузки во всех окнах; нативный заголовок в той же теме; без вспышки неверной темы при открытии окна.

**Non-Goals:** отдельные тёмные растровые изображения (растровых картинок в интерфейсе нет); тёмная тема каталога `/dev` сверх того, что даёт сама палитра; тёмные варианты для страницы 404 Next.

## Decisions

### 1. Палитра: те же роли, другие значения

Тёмная тема — блок `.dark { … }` после `:root` с теми же именами токенов. Компоненты не знают о теме, кроме нескольких мест из решения 3.

| Роль | Светлая | Тёмная |
|---|---|---|
| `surface` (окно, сайдбар) | `#f5f5f4` | `#131211` |
| `bg` (панель, карточки) | `#ffffff` | `#1c1b19` |
| `popover` (меню, диалоги) | = `bg` | `#252321` |
| `secondary` (вторичная кнопка) | = `surface` | `#2a2826` (выше панели, а не «дыра» в ней) |
| `border-hairline` / `border-strong` | `#e7e7e5` / `#d1d1ce` | `#2f2d2a` / `#45423e` |
| `text` / `text-muted` / `text-subtle` | `#111111` / `#6b6b6b` / `#8a8a87` | `#edebe7` / `#a6a39d` / `#8a8781` |
| `on-ink` (текст на основной кнопке) | `#ffffff` | `#161514` |
| `accent` / `accent-soft` / `accent-ink` | `#f58827` / `#fef1e6` / `#9a4a0c` | `#ec8a3a` / `#33241a` / `#f4ab6e` |
| `confirmed` / `assumption` / `contradiction` | тёмные на светлом | `#5bbb8b` / `#82a8e0` / `#ef6e66`, мягкие фоны — тёмные оттенки того же тона |
| `ring` | `#707070` | `#8f8b85` |

- **Тёплый, не сине-серый.** Все нейтральные — с тем же тёплым оттенком, что светлые серые (`#f5f5f4`, `#d1d1ce`), но почти чёрные.
- **Высота — светлее.** `surface` < `bg` < `popover`. Вложенные «утопленные» элементы на панели (поля пути, чипы, плитки иконок, блок «Коротко») остаются `surface`, то есть темнее панели, как в светлой теме они серее белого.
- **Чернила становятся светом.** `primary = text`, поэтому основная кнопка светлая с тёмным текстом; инверсные элементы (подсказки, отмеченный чекбокс, «Вы» в расшифровке) тоже светлые. Ховер основной кнопки — темнее (`#d4d1cc`), нажатие — ярче (`#ffffff`).
- **Акцент.** Оранжевый чуть мягче (`#ec8a3a`), текст на нём остаётся тёмным. `accent-ink` (оранжевый текст на `accent-soft`) — светлый оранжевый.
- **Контраст** (к панели `#1c1b19`). Основной текст ~14:1, `text-muted` ~6.8:1, `text-subtle` ~4.8:1 — не ниже, чем в светлой (`#8a8a87` на белом ~3.5:1). Статусные цвета как текст: зелёный ~7:1, синий ~7:1, красный ~5.3:1. Деструктивная кнопка — тёмный текст на `#ef6e66` (~5.6:1).

### 2. Глубина без теней

Тени в `@theme inline` стали ссылками: `--shadow-card: var(--depth-card)` и т. д. В `:root` у `--depth-*` прежние значения (светлая тема не меняется ни на пиксель), в `.dark`:
- `touch`, `card-sm`, `card` — внутренняя волосяная линия `inset 0 0 0 1px rgb(255 255 255 / 5–6%)`;
- `float` — светлая линия плюс тёмная тень `0 16px 48px rgb(0 0 0 / 45%)`: плавающие карточки в браузере лежат поверх картинки рабочего стола, и тень отделяет их от неё.

Ореол фокуса поля (`field-focus`) — `var(--field-halo)`: 6% чернил в светлой, 8% белого в тёмной.

### 3. Захардкоженные цвета

| Где | Было | Стало |
|---|---|---|
| Затемнение под `Dialog` / `AlertDialog` | `bg-foreground/16` | `bg-scrim` (светлая: те же 16% чернил, тёмная: 55% чёрного) |
| Оверлеи внутри панели (проект, интеграции, расшифровка) | `bg-foreground/20…24` | + `dark:bg-scrim` |
| `Sheet`, `Drawer` | `bg-black/10` | + `dark:bg-black/55` |
| Контур карточки в прозрачном окне (`desktop-stage`) | `rgb(17 17 17 / 8%)` | `var(--color-edge)` (светлая — то же, тёмная — 10% белого) |
| Ползунок `Slider` | `bg-white` | `bg-background` |
| Бегунок `Switch` | тень `rgb(17 17 17 / 20%)` | без тени в тёмной; выключенный — `muted-foreground` на `border-strong`, включённый — тёмный на светлой дорожке |
| GitHub, Outline (`brand-icons`) | `fill="#181717"` / `#000000` | `fill="currentColor"`, цвет `text-[#181717]` / `text-[#000000]`, в тёмной `dark:text-foreground` |
| Картинка рабочего стола в браузере (`desktop-scene`) | серые Paper | `dark:` — тёмный рабочий стол и окно Zoom того же устройства |

ClickUp (`#7B68EE`), Claude (`#D97757`) и Zoom (`#0B5CFF`) остаются в своих цветах: на тёмном они различимы.

### 4. Как настройка доходит до окна

- `ThemeProvider` (next-themes): `attribute="class"`, `enableSystem`, `defaultTheme="light"`, `themes=["light","dark"]`, `storageKey="grill.theme"`. Он ставит `.light` / `.dark` и `color-scheme` на `<html>` (скроллбары и нативные поля в теме), а для `system` слушает `prefers-color-scheme` и меняет класс на лету.
- `ThemeSync` (`src/features/shell/theme-sync.tsx`) в `AppFrame` — во всех окнах, включая онбординг, `/widget` и `/overlay`. Он читает `settingsStore` и вызывает `setTheme(theme)`, когда настройки прочитаны (`status === "ready"`) и страница гидрирована. Неизвестное значение — `light`.
- **Все окна сразу.** Смена в настройках пишет `settings_update`; Rust шлёт `DataChanged { entity: "settings" }` всем окнам, каждое перечитывает настройки, `ThemeSync` применяет новую тему. Перезагрузки нет. Плавающие окна уже имеют право `settings_get`.
- **Без вспышки.** Inline-скрипт next-themes до первой отрисовки ставит тему из `localStorage["grill.theme"]` — последнюю применённую в любом окне (у окон Tauri общий origin). Пока настройки не прочитаны, `ThemeSync` ничего не трогает, поэтому значение по умолчанию (`light`) из пустого стора не мелькает. Окна к тому же создаются скрытыми и показываются уже загруженными. Подтверждено тестом `tauri-theme.test.tsx`.
- **Браузерное демо.** Мок-настройки лежат в `localStorage["grill.settings"]`, поэтому тема переживает перезагрузку и там.

Отклонённая альтернатива: читать тему в каждом окне через `getCurrentWindow().theme()` / `onThemeChanged`. Она дублирует `prefers-color-scheme`, требует прав окна и не решает вспышку.

### 5. Нативный вид окон — в Rust

`windows::apply_theme(app, theme)` вызывает `AppHandle::set_theme`: `light` → `Some(Theme::Light)`, `dark` → `Some(Theme::Dark)`, `system` → `None` (следовать системе). На macOS это `NSApp.appearance`: заголовок, «светофор», нативные меню и диалоги, и `prefers-color-scheme` в WKWebView. Тема общая для всех окон, включая те, что откроются позже; на Windows Tauri проходит по окнам сам.

Где вызывается — там же, где другие эффекты настроек:
- при старте и после «Повторить» открытия базы (`apply_stored`);
- в `settings_update`, если в патче есть `theme` (`apply_settings`);
- после «Удалить всё» — тема сбрасывается к светлой вместе с автозапуском и клавишами.

С `None` окно следует за системой само, поэтому «Как в системе» меняет и заголовок, и страницу (через `prefers-color-scheme`) без кода в приложении.

Почему не из JS (`getCurrentWindow().setTheme`): нужно новое право окна в трёх capability-файлах, и при старте окно сначала показалось бы в системной теме до загрузки страницы. Rust применяет тему до показа любого окна.

Фон окна (`set_background_color`) не задаётся: на macOS он не реализован для слоя webview, а окна показываются уже отрисованными.

## Risks / Trade-offs

- **Первое окно после смены темы в другом процессе.** Если `localStorage` очищен, первое окно откроется светлым и переключится после чтения настроек. Это случается только после ручной очистки данных WebView.
- **Инверсные элементы.** Подсказки, отмеченные чекбоксы и реплики «Вы» в тёмной теме светлые. Это сохраняет язык дизайна («чернила — это действие или вы»), но это самые яркие пятна на экране.
- **Сторонние цвета Zoom.** Синий знак Zoom на тёмном ~3:1 — это логотип, не текст.

## Migration Plan

Миграций нет: ключ `theme` и его значения уже есть, по умолчанию `light`. Откат — вернуть `forcedTheme="light"` и неактивные варианты.
