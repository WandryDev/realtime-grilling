# Бриф проекта: «Единая система приёма звонков» для сети клиник «Дента Плюс»

Обновлён: перед звонком, по материалам Outline и ClickUp.

- B1. Клиент — сеть стоматологических клиник «Дента Плюс»: 6 филиалов в Одессе и 2 в Николаеве. Головной офис и call-центр — в Одессе, на Фонтанской дороге.
- B2. Сейчас у каждого филиала свой городской номер и свой мобильный. Звонки принимают администраторы на ресепшене, параллельно с живыми пациентами в холле. Единого номера нет.
- B3. Боль, которую назвал клиент на первой встрече: в часы пик (9:00–11:00 и 17:00–19:00) пропускается, по оценке клиента, до 30% входящих. Пропущенные никто системно не перезванивает, пациенты уходят в другие клиники.
- B4. Цель проекта на первом этапе: единый номер, распределение звонков между филиалами и колл-центром, запись разговоров, перезвон по пропущенным. На втором этапе — аналитика и скрипты для администраторов.
- B5. Телефония сейчас: облачная АТС «Бинотел» в трёх филиалах, в остальных — обычные мобильные операторов. Договор с Бинотел действует до марта следующего года.
- B6. МИС (медицинская информационная система) — «Стоматология 3.0», расписание врачей и карточки пациентов ведутся там. У МИС есть REST API, документация неполная; доступ к API даёт подрядчик МИС, по запросу, срок ответа до двух недель.
- B7. CRM: используется Битрикс24, но только для маркетинга (заявки с сайта и рекламы). Администраторы в Битрикс24 почти не заходят.
- B8. Колл-центр: сейчас 3 оператора, работают с 8:00 до 20:00 по будням и с 9:00 до 15:00 в субботу. Клиент рассматривает расширение до 5 операторов.
- B9. Бюджет первого этапа, по словам клиента на первой встрече, — «в пределах 15 тысяч долларов, включая лицензии на год». Сроки: запуск до начала сезона, ориентир — 1 сентября.
- B10. Ограничения: записи разговоров с пациентами содержат медицинские данные; юрист клиента требует хранения на серверах в Украине или в ЕС, и срока хранения не дольше 1 года.
- B11. Наша сторона: уже делали для клиента лендинг и интеграцию сайта с Битрикс24 (заявки). Опыт с API «Стоматология 3.0» — нет.
- B12. Открытые риски из ClickUp: (а) неизвестно, кто со стороны клиента будет владельцем системы после запуска; (б) не согласовано, остаются ли номера филиалов или переходим на один номер; (в) нет данных о реальном объёме звонков — 30% пропущенных это оценка, не замер.
