# Grill — спецификация дизайна для отрисовки экранов

Этот документ — общий бриф для всех, кто рисует экраны в Paper. Всё, что ниже, уже согласовано с владельцем продукта. Не изобретай новый стиль — повторяй эталон.

## Продукт (коротко)

Десктоп-приложение (Tauri, macOS + Windows) для менеджера агентства. Во время звонка с клиентом оно локально транскрибирует разговор (канал «Вы» — микрофон, канал «Клиент» — системный звук, без разделения голосов внутри) и через локальный CLI-агент (Claude Code) **само** подсказывает вопросы, которые стоит задать клиенту. Менеджер ничего не печатает во время звонка. Подробный концепт: `docs/concept.md`.

Ключевые сущности: Проект → Люди клиента (профили: темперамент, тех. уровень, роль, понимание проекта) → Звонок → Темы (карточки задач) → Вопросы. Интеграции (все опциональные): Outline (доки, API-ключ), GitHub (код, OAuth device flow), ClickUp (задачи, OAuth, только чтение). После звонка: summary, TL;DR, незакрытые вопросы, предложения обновить бриф проекта и профили клиентов (только по подтверждению).

Пример данных (используй последовательно): проект «Телемедиа», клиенты Ольга Демченко (CEO, мало понимает в технике), Игорь Савчук (техлид клиента), темы «Приём звонков», «Интеграция с CRM». Другие проекты: «Ветклиника Лапа», «Логистик Про», «Школа Ритм». Менеджер — Дима. Разработчик в ClickUp — Андрей, дизайнер — Марта. Репозитории `telemedia/backend`, `telemedia/web`. Коллекция Outline «Телемедиа». Время звонков в районе 12:00–12:40.

## Жёсткие правила стиля (от владельца продукта)

1. **Никакого uppercase** (`text-transform`) и **никакой широкой разрядки** (letter-spacing > 0). Допустимо только `--tracking-tight` на крупных заголовках.
2. **Никаких точек «·» как разделителей** в тексте. Используй запятые, предлоги, отдельные элементы с gap.
3. **Скругления в духе shadcn Luma** (macOS Tahoe без стекла): кнопки и пилюли — `--radius-full`; поля ввода — `--radius-sm` (12); карточки и вопросы — `--radius-md` (18); окна, плавающие панели, диалоги — `--radius-lg` (26); главная белая панель внутри окна — 20px.
4. **Мягкие тени вместо рамок**. Карточка: `0 1px 2px rgba(17,17,17,0.04), 0 8px 24px rgba(17,17,17,0.05)`. Плавающее (диалог, виджет, док): `0 0 0 1px rgba(17,17,17,0.06), 0 12px 40px rgba(17,17,17,0.10)`. Рамка 1px `--color-border` — только для разделителей и полей ввода.
5. **Акцент `#F58827` (`--color-accent`)** — только мелкие насыщенные метки (точки, курсор, полоска прогресса, счётчик) и одна главная вещь на экране. Большие плашки — только `--color-accent-soft` с текстом `--color-accent-ink`. Не заливай крупные блоки насыщенным оранжевым.
6. Статусы: подтверждено/отвечено `--color-confirmed` (+`-soft`), допущение `--color-assumption` (синий, +`-soft`), противоречие/ошибка `--color-contradiction` (+`-soft`), пусто `--color-empty`. Запись — `--color-recording`.
7. Главная чёрная кнопка — одна на экран (`--color-text`, текст `--color-on-ink`). Остальные — серые пилюли `--color-surface` или текстовые. Исключение: подтверждение деструктивного действия в диалоге (удалить проект, отключить интеграцию, очистить всё) — красная пилюля `--color-contradiction` с белым текстом вместо чёрной.
8. Шрифты: Inter для всего интерфейса на всех страницах, включая эталон; system-ui не использовать. Inter (400/500/600, токен `--font-sans`), JetBrains Mono (`--font-mono`) только для времени, счётчиков, путей и id. Размеры: 12/13/14/16/20/28/40 (токены `--text-*`), крупный вопрос 28–32px.
9. Минимализм: меньше элементов, больше воздуха, информация прямо на поверхности, без лишних карточек-обёрток. Светлая тема.
10. Язык интерфейса — русский, живые реалистичные тексты. Иконки — простые SVG со stroke 1.4–1.6, без эмодзи.

## Каркас окна

- Артборд = окно приложения. Основные окна: 1440×900 (если контент длинный — `height: fit-content`, это «развёрнутый скролл»). `borderRadius: 26px`, `overflow: hidden`.
- Фон окна `--color-surface`, слева/справа контент прямо на сером, главная область — белая панель (radius 20, тень карточки), отступ 8px от краёв окна.
- Шапка 56px: три серых «светофора» macOS (`#DCDCDA`, 12px), название, справа пилюли действий.
- Для Windows-вариантов (где важно) — кнопки окна справа (свернуть/развернуть/закрыть) тонкими линиями.
- Плавающие виджеты (старт звонка, оверлей, предложение завершить): рисуй артборд-«рабочий стол» 960×600 с фоном `#E4E4E1` и условным окном звонилки (серый прямоугольник с подписью «Zoom» и логотипом), а виджет — поверх, в правом верхнем углу, с тенью плавающего элемента.

## Как показывать состояния и взаимодействия

- Каждое состояние — отдельный артборд. Имя: `<номер> <Экран> — <состояние>`, например `07 Ревью предложений — частично принято`.
- Раскладывай артборды рядами слева направо по сценарию, 80px между ними; новый сценарий — новый ряд.
- Взаимодействия подписывай заметками на холсте рядом с артбордами (обычный текст 14px `--color-text-muted` в отдельном небольшом артборде-«заметке» без фона, ширина 280): «Клик по „Вернуть“ → вопрос возвращается в открытые» и т.п. Ховеры, раскрытые меню, фокусы показывай прямо на макете в нужном состоянии.

## Процесс

1. `get_guide({topic:"paper-mcp-instructions"})`, `get_font_family_info` (Inter, JetBrains Mono), `get_screenshot` + `get_jsx` эталона `MQ-0`.
2. Создай свою страницу (`create_page`) и работай только на ней (передавай `pageId`).
3. Пиши маленькими порциями, после каждого экрана — скриншот и самопроверка (отступы, выравнивание колонок, контраст, обрезка → `height: fit-content`).
4. В конце `finish_working_on_nodes` со своими id и короткий отчёт: список артбордов с состояниями, созданные токены, что не успел.

## Решения владельца продукта (после первой отрисовки)

- Отмена деструктивного действия: тост с «Вернуть» живёт 8 секунд.
- Вход в ClickUp через браузер: ожидание 10 минут, потом состояние «ошибка, попробовать снова».
- Логотип сервиса в строке списка ставится слева от названия, не после него. Колонки статуса и действий в повторяющихся строках — слоты фиксированной ширины.
- Почта, имя приложения в системных диалогах (`zoom.us`) и крупные цифры статистики набираются Inter, не моноширинным.
- Главный вопрос (hero-карточка вопроса) — радиус 26 (`--radius-lg`), как в эталоне. Меню и поповеры, привязанные к полю или кнопке — 18, пункты меню — 12. Тултип — 8.
- Выбранный якорь темы в звонке остаётся чёрным (ядро эталона). Выбранные фильтры и вкладки на остальных экранах — белый сегмент `--color-bg` с тенью `0 1px 2px rgba(17,17,17,0.08)` на дорожке `--color-surface`, текст `--color-text` 500.
- Поля ввода: в покое рамка `--color-border-strong`, при наведении `--color-text-subtle`, в фокусе рамка `--color-text` и нейтральный ореол 3px `rgba(17,17,17,0.06)`.
