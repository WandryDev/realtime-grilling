# Спайки: технические риски

Прототипы и замеры по разделу «Технические риски» из [`concept.md`](../concept.md). Проверено 2026-11-02 на MacBook Air M3, 16 ГБ, macOS 26.6. Windows-машины не было.

Код лежит в `spikes/`. Это одноразовые прототипы: они не входят в `src-tauri`, CI их не собирает, Biome не проверяет. Модели, аудио и сырые логи в git не попадают.

## Что из этого следует для разработки

- **Звук.** Детект конца звонка делаем на слушателях Core Audio: учитываем ввод и вывод, исключаем свои PID и ставим дебаунс. Системный канал берём через process tap. Эхоподавление — AEC3 на канале «Я», с тапом (macOS) или loopback (Windows) как опорным сигналом. VoiceProcessingIO не используем.
- **STT.** Конвейер такой: Silero VAD → фраза → whisper.cpp turbo q5_0 с глоссарием в `prompt`. VAD перед моделью обязателен. Кроме него нужна проверка «ответ ≈ текст промпта»: на тишине модель может выдать сам глоссарий. Пороги `no_speech` / `logprob` не помогают.
- **Агент.** Флаги и формат вызова описаны в [agent.md](agent.md), раздел «Рекомендуемый вызов». Haiku через CLI и пользовательский конфиг по умолчанию для быстрого контура не годятся. Логируем `utilization` из `rate_limit_event`.

## Открыто: что нужно от людей

1. **Windows-машина менеджера** (CPU, GPU, RAM). Нужно прогнать `spikes/audio` (loopback, детект микрофона) и `spikes/stt/run_windows.ps1`. По оценке turbo на Windows без GPU в реальном времени не тянет. Если оценка подтвердится, остаются GigaAM для ru, `small` для uk или облачный STT.
2. **Реальные записи 5–10 звонков.** STT мерили на синтетике (`say`), поэтому абсолютный WER на живой речи будет хуже.
3. **Лимиты подписки.** Нужно посмотреть `utilization` на 1–2 живых звонках на целевом тарифе. Оценка — 15–20 п.п. 5-часового окна за час звонка.
4. **Ручные проверки на Mac.** Здесь у приложения, из которого запускались тесты, не было доступа к микрофону:
   - реальный ERLE;
   - ducking на слух;
   - mute в Zoom и Meet: держит ли звонилка микрофон.

   Команды — в [audio.md](audio.md), раздел «Что нужно сделать руками».
